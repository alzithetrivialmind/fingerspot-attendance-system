# Berkontribusi

Laporan bug, hasil uji dengan tipe mesin lain, dan pull request sangat diterima.

- Untuk bug, sertakan tipe mesin, langkah, dan log aplikasi.
- **Jangan sertakan data asli**: nama karyawan, PIN, Cloud ID, nomor seri, API key, atau template sidik jari. Samarkan dulu.
- Jalankan `pytest` sebelum membuat pull request dan tambahkan tes untuk perilaku baru.
- Teks di tampilan memakai bahasa Indonesia.
- Bila mengubah file JS atau CSS, naikkan `?v=` di `app/templates/index.html` atau `monitor.html`.
- Aturan khusus satu perusahaan (kode jam, lembur, penggajian) di luar cakupan proyek ini.
